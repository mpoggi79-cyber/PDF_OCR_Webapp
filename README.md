# PDF OCR Webapp

Trasforma PDF in Markdown pulito, leggibile e pronto da usare.

PDF OCR Webapp e' una web app semplice e diretta che converte le pagine di un PDF in immagini e le passa a un modello OCR in locale tramite Ollama, per ottenere testo strutturato in formato Markdown. Il risultato e' un flusso rapido, pratico e privato: carichi il documento, avvii l'elaborazione e ottieni contenuti gia' organizzati per note, report, knowledge base o archiviazione tecnica.

## Perche' usarlo

- OCR locale con Ollama: nessun servizio cloud obbligatorio.
- Output in Markdown: pulito, portabile, facile da riutilizzare.
- Supporto batch: elabora piu' PDF in sequenza.
- Interfaccia web leggera: nessun setup complesso lato frontend.
- Progetto pensato per essere esteso: ideale per nuove funzionalita' e flussi personalizzati.

## In una frase

Da PDF a Markdown, in locale, con un'esperienza veloce e concreta.

## Quick Start

1. Avvia Ollama in locale e assicurati di avere disponibile il modello glm-ocr.
2. Esegui start.bat per creare l'ambiente e avviare il server.
3. Apri l'app nel browser e carica uno o piu' PDF.
4. Avvia l'OCR sulle pagine o sull'intero batch.
5. Esporta il risultato finale in Markdown.
